🎮 Exemplos de Uso do Widget de Nível

Widget Completo

<div id="widget-nivel" 
     data-parceiro-id="UUID">
</div>

Widget Compacto

<div id="widget-nivel" 
     data-parceiro-id="UUID"
     data-compact>
</div>

Sem Barra de Progresso

<div id="widget-nivel" 
     data-parceiro-id="UUID"
     data-no-progress>
</div>

Sem Badges

<div id="widget-nivel" 
     data-parceiro-id="UUID"
     data-no-badges>
</div>

📝 Instruções de Uso

1. Incluir os scripts necessários:

<!-- Supabase -->
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>

<!-- Config Centralizado -->
<script src="/supabase-config.js"></script>

<!-- Widget de Nível -->
<script src="/js/widget-nivel.js"></script>

2. Adicionar o container do widget:

<div id="widget-nivel" data-parceiro-id="UUID-DO-PARCEIRO"></div>

3. Opções disponíveis (atributos data):

  • data-parceiro-id - Obrigatório: UUID do parceiro
  • data-compact - Modo compacto (uma linha)
  • data-no-progress - Ocultar barra de progresso
  • data-no-badges - Ocultar badges conquistados

4. Inicialização automática:

O widget é inicializado automaticamente quando a página carrega. Não é necessário código JavaScript adicional!

5. Inicialização manual (opcional):

<script>
  // Inicializar após carregar dados do parceiro
  WidgetNivel.init();
  
  // Ou com opções personalizadas
  WidgetNivel.init({
    containerId: 'meu-widget',
    compact: true,
    showProgress: false
  });
</script>
