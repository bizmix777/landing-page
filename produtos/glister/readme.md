# 🦷 Glister Multi-Action Landing Page

Landing page de alta conversão para o creme dental **Glister 200g da Amway**, desenvolvida com base nos princípios de copywriting e estratégia de **Alex Hormozi**.

---

## 📋 **Sobre o Projeto**

Esta landing page foi criada para maximizar a conversão de vendas do produto Glister, utilizando:

- ✅ **Copy persuasiva** baseada no framework PAS (Problem-Agitate-Solution)
- ✅ **Design moderno** com paleta de cores estratégica
- ✅ **Responsividade mobile-first**
- ✅ **Animações sutis** para melhor experiência do usuário
- ✅ **3 opções de conversão** (compra simples, desconto, revenda)
- ✅ **Garantia de 30 dias** para reversão de risco
- ✅ **Prova social** com testemunhos reais e estudos científicos
